# 📱 Guía de Uso: Mercado Pago

Mercado Pago funciona como una cuenta digital gratuita donde tu dinero genera rendimientos diarios, ofrece una tarjeta (crédito/débito) y acceso a créditos sin tarjeta.

## 🛠️ Prestaciones Principales

| Para Usuarios (Compradores) | Para Vendedores (Negocios) |
| :--- | :--- |
| Pagar servicios y recargas | Cobrar con QR y Link de Pago |
| Enviar dinero a amigos/familia | Usar el lector de tarjetas **Point** |
| Invertir saldo automáticamente | Gestionar estadísticas de ventas |
| Acceder a créditos personales | Adelantar el cobro de tus ventas |

## 🚀 Cómo Empezar

* **Registro:** Descarga la app y valida tu identidad con una foto de tu DNI y una selfie (biometría).
* **Carga de Saldo:** Ingresa dinero mediante transferencia bancaria (CVU), débito inmediato o efectivo en puntos habilitados.
* **Operación:**
    * **Pagos QR:** Escanea el código en comercios físicos para pagar sin contacto.
    * **Inversión:** Activa la opción de rendimientos para que tu saldo crezca día a día.
* **Extracción:** Puedes retirar tu dinero en cajeros automáticos o comercios adheridos usando tu tarjeta Mercado Pago.

### ⚙️ Cómo funciona

1.  **Creas una cuenta:** Es gratis y se hace desde la app o web, asociando tu email y teléfono.
2.  **Agregas dinero:** Puedes depositar desde una cuenta bancaria, recibir transferencias o efectivo.
3.  **Realizas operaciones:** Pagos con QR, envíos de dinero por Alias o cobros con Link de Pago.
4.  **Gestionas tu dinero:** El saldo genera ganancias automáticamente y puedes usarlo con la tarjeta.

> **Nota Importante:** A diferencia de un banco, no pagas mantenimiento de cuenta, pero recuerda que cobrar tiene comisiones asociadas.

## 💰 Comisiones por Cobro (Vendedores)

El costo varía según la disponibilidad del dinero en tu cuenta:

| Método de Cobro | Disponibilidad | Comisión (Aprox. + IVA) |
| :--- | :--- | :--- |
| **QR (Dinero en cuenta)** | En el momento | **0,8%** |
| **QR (Tarjeta de Débito)** | En el momento | **3,5%** |
| **Link de Pago / Web** | En el momento | **5,99%** |
| **Link de Pago / Web** | A los 14 días | **3,49%** |
| **Point (Lector físico)** | En el momento | **3,39% (D) / 4,5% (C)** |

> **Tip para el vendedor:** En la sección `Tu Negocio > Costos` puedes configurar estos plazos para pagar menos comisión.

## 🛡️ Seguridad: Protege tu Cuenta

1.  **Verificación en dos pasos (2FA):** Activa Google Authenticator o SMS para iniciar sesión.
2.  **Biometría y Bloqueo:** Configura la app para pedir huella o FaceID (`Perfil > Seguridad`).
3.  **Personas de Confianza:** Designa contactos que puedan bloquear tu cuenta en caso de robo de tu móvil.

## 💡 Consejos Anti-Fraude
* **Nunca compartas códigos SMS:** Mercado Pago jamás te los pedirá.
* **Verifica el nombre:** Revisa el nombre del titular antes de confirmar un envío.

## 💳 Mercado Crédito: Cuotas sin Tarjeta

Es una línea de crédito para compras en **Mercado Libre**, pagos de servicios o recargas.

### 🔍 ¿Cómo funciona?
* **Activación:** Se solicita desde la sección "Mercado Crédito" en la app. El sistema te asigna un **Límite Disponible**.
* **Uso:** Seleccionas este medio de pago al finalizar una compra.
* **Cuotas:** Eliges de 1 a 12 cuotas fijas.

### ⚠️ Puntos clave
* **Intereses:** Aplica un recargo financiero según tu perfil crediticio.
* **Vencimiento:** Paga a tiempo para evitar moras y bloqueos.

## ❓ Preguntas Frecuentes (FAQ)

**1. ¿Es seguro dejar mi dinero en la cuenta?**
Sí, cuenta con estándares de seguridad bancaria y el respaldo de un fondo común de inversión con disponibilidad inmediata.

**2. ¿Qué pasa si pierdo mi celular o me lo roban?**
* **Acción inmediata:** Entra a la web desde una computadora para **desvincular dispositivos** (es como cambiar la cerradura a distancia).
* **Personas de confianza:** Si configuraste esta opción, ellos pueden reportar el robo por ti desde sus propias cuentas.

**3. ¿Puedo usar la tarjeta en el exterior?**
Sí, es una tarjeta **Mastercard internacional**. Se puede usar en cualquier comercio que acepte la red.

**4. ¿Cómo retiro efectivo sin tarjeta física?**
Puedes generar un código de retiro para usar en **Rapipago** o solicitar efectivo en cajas de supermercados adheridos usando el **código QR**.
